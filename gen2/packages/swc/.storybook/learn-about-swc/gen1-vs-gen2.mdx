# Gen1 vs Gen2

Decide whether to adopt SWC Gen2 (`@adobe/spectrum-wc`), and when to move your Gen1 app to it.

- **For:** application developers and engineering leads planning SWC work

## What changed in Gen2

Gen2 brings full-fidelity Spectrum 2 styles, a more consistent architecture, and updated component APIs and accessibility contracts.

| Area               | SWC Gen1                                                                                             | SWC Gen2                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Package name       | `@spectrum-web-components`                                                                           | `@adobe/spectrum-wc`                                                                       |
| Documentation site | [opensource.adobe.com/spectrum-web-components](https://opensource.adobe.com/spectrum-web-components) | [spectrum-web-components.adobe.com](https://spectrum-web-components.adobe.com)             |
| Design             | Includes Spectrum, Express, and S2 Foundations themes                                                | Spectrum 2 only                                                                            |
| Architecture       | Earlier component patterns; less consistent                                                          | More consistent structure and APIs across the library                                      |
| Styling            | Components are styled via `<sp-theme>`                                                               | Components styled via CSS classes at application root, such as `swc-theme swc-theme--dark` |
| Customization      | Done via `--mod` CSS custom properties                                                               | Done via `--swc` custom properties and/or global element styles                            |
| Accessibility      | Basic support, several known bugs                                                                    | Improved accessibility coverage, bugs fixed                                                |
| Performance        | More interdependencies, larger bundles                                                               | Smaller bundles, higher reliance on browser standards, better runtime performance          |
| Long-term support  | No new components or features, minimal bug fixes                                                     | New features, components, and fixes                                                        |

## Should you migrate, and when?

| If you…                                      | Do this                                                                                                                                                                               | When                         |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Start a new project                          | Use `@adobe/spectrum-wc` wherever a Gen2 component exists.                                                                                                                            | Now                          |
| Maintain a Gen1 app                          | Plan to adopt Gen2 one component at a time, as each Gen2 version ships.                                                                                                               | Start planning now           |
| Need a fix for a Gen1 bug                    | Check the [Gen1 bug policy](/docs/resources-support-and-compatibility--docs#gen1-bug-policy). Gen1 fixes cover SEV1 and SEV2 bugs only; other bugs are addressed in the Gen2 version. | When the Gen2 version ships  |
| Use a component that has no Gen2 version yet | Keep that component on Gen1, next to your Gen2 components.                                                                                                                            | Until its Gen2 version ships |

To see which components have a Gen2 version, browse the **Components** section of the sidebar. Each migrated component has a **Migration guide** page.

## How Gen1 and Gen2 coexist

Gen1 and Gen2 run in the same app, so you can migrate one component or one screen at a time. Four properties make that work:

- **Different package names:** `@spectrum-web-components/*` and `@adobe/spectrum-wc` install side by side without conflicts.
- **Different tag prefixes:** `<sp-badge>` and `<swc-badge>` are independent custom elements, so both can share one tree.
- **Shared visual language:** Gen1's `spectrum-two` theme bridges Spectrum and Express to Spectrum 2, which Gen2 uses by default. Gen1 components in that theme look consistent with their Gen2 neighbors.
- **Separate token namespace:** Gen2 design tokens use the `swc` namespace, so they don't conflict with Gen1 visuals.

The Gen1 `<sp-theme>` element only affects its `<sp-*>` descendants. The Gen2 `swc-theme*` classes only affect `<swc-*>` descendants, so the two systems don't interfere.

## What does running both cost?

Running Gen1 and Gen2 together is expected during migration. Keeping both versions of the same component on a page ships extra component code and loads CSS custom properties you don't need. Migrating by route or feature area keeps the time that any one page loads both versions short.
