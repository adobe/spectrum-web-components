## Usage

Use **one attachment layout type per attachment strip**. Pick either:

- **`type="card"`**: metadata-first files (title, subtitle, small thumbnail). Best when the strip is document-only and filenames or file types matter more than visual preview.
- **`type="media"`**: square preview tiles, with an optional **`badge`** slot for file-type labels (for example, "PDF")

Do not slot `card` and `media` attachments together in the same prompt field or wrapping row.

When a single upload batch mixes **images and documents**, normalize the whole strip to **`type="media"`**: use image previews in `thumbnail` for photos, and thumbnail plus **`badge`** for documents. Do not render images as `media` and documents as `card` in the same session.

The tile's own accessible name and its Close button's accessible name ("Remove [file name].[file type]") derive automatically from the `title` slot's text content; set `accessible-label` / `dismiss-label` to override. This tile has no default `tabindex` of its own; `swc-prompt-field` manages roving `tabindex` and keyboard focus for tiles slotted into its `attachment` slot.

## Options

### Multi card

Several card attachments in one strip, similar width to the prompt-field composer attachment region.

<Canvas of={UploadAttachmentStories.MultiCard} />

### Multi media

Several media tiles in one strip, with and without badge overlays.

<Canvas of={UploadAttachmentStories.MultiMedia} />

### Card

Card type uses a compact thumbnail with horizontal text layout.

<Canvas of={UploadAttachmentStories.Card} />

### Media

Media type uses a larger preview region without title and subtitle text.

<Canvas of={UploadAttachmentStories.Media} />

### Media with badge

Use `type="media"` with an optional `badge` slot when the preview needs a file-type label (for example, a document thumbnail with a bottom-left "PDF" tag).

<Canvas of={UploadAttachmentStories.MediaWithBadge} />

### Text overflow

Subtitle truncates with a trailing ellipsis when the attachment is narrower than the text. On `type="card"`, the title truncates in the middle instead: the start shortens with an ellipsis while the last few characters and file extension stay pinned, so the file type stays visible even when the name is clipped.
