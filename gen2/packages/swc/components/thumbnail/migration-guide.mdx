# Thumbnail migration guide

Replace `<sp-thumbnail>` with `<swc-thumbnail>`, update the import, and remove `background`, `layer`, `disabled`, `focused`, and `selected`, none of which carry forward to Spectrum 2.

## Installation

```bash
# Remove
yarn remove @spectrum-web-components/thumbnail

# Add
yarn add @adobe/spectrum-wc
```

Update your import:

```js
// Before
import '@spectrum-web-components/thumbnail/sp-thumbnail.js';

// After
import '@adobe/spectrum-wc/components/thumbnail/swc-thumbnail.js';
```

> `@adobe/spectrum-wc` is a monolithic package. Importing via subpath (e.g., `@adobe/spectrum-wc/components/thumbnail/swc-thumbnail.js`) registers and loads only that component's bundle.

## What changed

### Renamed

| Area        | Spectrum 1 (`sp-thumbnail`)          | Spectrum 2 (`swc-thumbnail`)                                     |
| ----------- | ------------------------------------ | ---------------------------------------------------------------- |
| Tag         | `sp-thumbnail`                       | `swc-thumbnail`                                                  |
| Import path | `@spectrum-web-components/thumbnail` | `@adobe/spectrum-wc/components/thumbnail/swc-thumbnail.js`       |
| `size`      | String (`el.size === '500'`)         | Number (`el.size === 500`); the HTML attribute is still a string |
| `cover`     | Boolean attribute                    | `fit` attribute: `'cover'` or `'contain'` (default)              |

### Added in Spectrum 2

| Addition     | Notes                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| `decorative` | Boolean attribute. Hides the thumbnail (and its slotted image) from assistive technology with `aria-hidden="true"` |

### Removed in Spectrum 2

| Removed                | Replacement                                                                                                     |
| ---------------------- | --------------------------------------------------------------------------------------------------------------- |
| `background` attribute | None. Apply a background to a wrapping element if you still need custom letterboxing.                           |
| `layer` attribute      | Apply your own border styling directly to `<swc-thumbnail>` or a wrapping element.                              |
| `disabled` attribute   | Apply your own dimmed/opacity styling to `<swc-thumbnail>` from the parent component that is actually disabled. |
| `focused` attribute    | The parent interactive element that wraps the thumbnail draws its own focus ring.                               |
| `selected` attribute   | Apply your own selected-state styling (for example an outline) to `<swc-thumbnail>` from the parent component.  |

## Update your code

### 1. Rename the tag

```html
<!-- Before -->
<sp-thumbnail size="500">
  <img src="preview.png" alt="Layer 1 preview" />
</sp-thumbnail>
<!-- After -->
<swc-thumbnail size="500">
  <img src="preview.png" alt="Layer 1 preview" />
</swc-thumbnail>
```

### 2. Update numeric `size` access in JavaScript

The `size` attribute value is unchanged (`size="500"`). Only JavaScript that reads or sets `.size` as a property needs to switch to a numeric literal:

```js
// Before
thumbnail.size = '500';

// After
thumbnail.size = 500;
```

### 3. Replace `cover` with `fit`

```html
<!-- Before -->
<sp-thumbnail cover>
  <img src="preview.png" alt="Layer 1 preview" />
</sp-thumbnail>
<!-- After -->
<swc-thumbnail fit="cover">
  <img src="preview.png" alt="Layer 1 preview" />
</swc-thumbnail>
```

If you did not set `cover`, no change is needed: the new default, `fit="contain"`, matches the old unset behavior.

### 4. Remove `background`, `layer`, `disabled`, `focused`, and `selected`

Move any styling tied to these attributes into your own CSS, targeting `<swc-thumbnail>` directly:

```html
<!-- Before -->
<sp-thumbnail layer selected>
  <img src="preview.png" alt="Layer 1 preview" />
</sp-thumbnail>

<!-- After -->
<style>
  .layer-selected-thumbnail {
    outline: 2px solid var(--swc-focus-indicator-color);
  }
</style>
<swc-thumbnail class="layer-selected-thumbnail">
  <img src="preview.png" alt="Layer 1 preview" />
</swc-thumbnail>
```

### 5. (Optional) Adopt `decorative`

Set `decorative` when the slotted image's content is already described by surrounding text:

```html
<!-- Before -->
<sp-thumbnail>
  <img src="preview.png" alt="" />
</sp-thumbnail>

<!-- After -->
<swc-thumbnail decorative>
  <img src="preview.png" alt="" />
</swc-thumbnail>
```

## Accessibility

- Every slotted `<img>` needs a meaningful `alt`, or the thumbnail needs `decorative` set. In dev builds, a missing accessible name now triggers a console warning. See [step 5](#5-optional-adopt-decorative).

### Removed `--mod-thumbnail-*` properties

| Removed (Spectrum 1)                        | Replacement (Spectrum 2) |
| ------------------------------------------- | ------------------------ |
| `--mod-thumbnail-size`                      | `--swc-thumbnail-size`   |
| `--mod-thumbnail-border-color`              | No replacement           |
| `--mod-thumbnail-border-color-selected`     | No replacement           |
| `--mod-thumbnail-border-radius`             | No replacement           |
| `--mod-thumbnail-border-width`              | No replacement           |
| `--mod-thumbnail-border-width-selected`     | No replacement           |
| `--mod-thumbnail-color-opacity-disabled`    | No replacement           |
| `--mod-thumbnail-focus-indicator-color`     | No replacement           |
| `--mod-thumbnail-focus-indicator-gap`       | No replacement           |
| `--mod-thumbnail-focus-indicator-thickness` | No replacement           |
| `--mod-thumbnail-layer-border-color-inner`  | No replacement           |
| `--mod-thumbnail-layer-border-color-outer`  | No replacement           |
| `--mod-thumbnail-layer-border-width-inner`  | No replacement           |
| `--mod-thumbnail-layer-border-width-outer`  | No replacement           |
