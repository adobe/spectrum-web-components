# Component accessibility specification documents

You're working on a component accessibility specification document for a migrated or new gen2 component, including the "analyze accessibility" migration step. A 1st-gen predecessor is not required.

Before you write or change content, load the `component-accessibility-specification` skill at `.ai/skills/component-accessibility-specification/SKILL.md`. It defines the required section order, the ARIA recommendations structure, Shadow DOM guidance, keyboard and focus conventions, and the testing table format.
