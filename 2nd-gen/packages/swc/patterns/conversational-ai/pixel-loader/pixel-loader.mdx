## Anatomy

A pixel loader consists of:

- A **grid of pixel cells** that drop and fade into place to assemble the
  active icon, then drop and fade away to disassemble it before the next loop

### Sizing

The loader has no `size` attribute. Set its rendered size by overriding the
`--swc-pixel-loader-size` custom property in your own CSS (it defaults to
56px):

```css
swc-pixel-loader {
  --swc-pixel-loader-size: 24px;
}
```

## States

### States

`paused` renders the fully-settled appearance (full opacity, no offset) with
no animation, matching the resting state used for `prefers-reduced-motion`.

## Accessibility

### Features

The `<swc-pixel-loader>` element implements the following accessibility
features:

- Host renders with `role="progressbar"`, with no `aria-valuenow` /
  `aria-valuemin` / `aria-valuemax` since progress is always indeterminate
- The `label` property (default `"Loading"`) sets the accessible name via
  `aria-label`
- The animation is skipped entirely (rendering the settled state) when the
  user has requested reduced motion

### Best practices

- Always provide a descriptive `label` that explains what's loading (for
  example `"Generating response"`) instead of relying on the default
  `"Loading"`
- Don't rely on the animation alone to convey that an operation is in
  progress for long-running operations; pair it with a visible status message
  elsewhere in the UI
