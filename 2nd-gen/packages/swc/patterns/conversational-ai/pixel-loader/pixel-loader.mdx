## Options

### Icons

The catalog includes 30 icons (see `data.ts`): a hand-authored logo mark plus
~29 generated glyphs. A representative sample is shown below.

<Canvas of={PixelLoaderStories.Icons} />

### Presets

A preset cycles through a themed sequence of icons, one per loop, instead of
looping a single icon forever.

<Canvas of={PixelLoaderStories.Presets} />

## States

### States

`paused` renders the fully-settled appearance (full opacity, no offset) with
no animation, matching the resting state used for `prefers-reduced-motion`.

<Canvas of={PixelLoaderStories.States} />

## Accessibility

This is a prototype implementation; accessibility semantics may evolve as the
component matures. Currently the host renders with `role="img"` and an
`aria-label` (via the `label` property, default `"Loading"`), and the
animation is skipped entirely (rendering the settled state) when the user has
requested reduced motion.
