## Anatomy

An infield button consists of a single pressable icon container. It has no text label; the required `accessible-label` attribute provides the accessible name.

### Content

#### Slots

- **icon slot**: Icon to display inside the button.

#### Attributes

- **accessible-label**: Required. Provides the accessible name applied as `aria-label` on the inner element.

## Options

### Sizes

Infield buttons inherit their size from the parent field. All four sizes are supported; the parent field sets the `size` attribute directly on the button.

<Canvas of={Stories.Sizes} />

### Quiet

The quiet treatment removes the background, leaving only the icon. Use it when the parent field uses a quiet variant.

<Canvas of={Stories.Quiet} />

## States

Infield buttons support default, disabled, quiet, and quiet-disabled states. The disabled state removes interactivity while preserving layout. The parent field is responsible for disabling all slotted infield buttons when the field itself is disabled or pending.

<Canvas of={Stories.States} />

## Accessibility

### Features

- **Not in the tab order**: Infield buttons set `tabindex="-1"` on the inner element. The parent field owns all keyboard behavior and supplies the only visible focus ring.
- **Accessible label required**: Each button must have an `accessible-label` attribute. A development warning fires if the attribute is absent on an icon-only button.
- **ARIA label**: The `accessible-label` value is applied as `aria-label` on the inner `<button>` element.

### Best practices

- Use action-describing labels (for example, `"Open country picker"`, `"Clear search"`, `"Increase quantity"`) rather than generic labels like `"Button"`.
- Disable all infield buttons in a field when the parent field is pending or disabled; do not rely on the button's own `pending` state.
